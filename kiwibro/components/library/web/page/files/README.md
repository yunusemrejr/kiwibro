# Responsive page

A single static page with semantic HTML and one phone-first stylesheet.

Run: open `index.html` in a browser, or serve the folder with `python3 -m http.server 8000`.

Edit the content marked with `KIWIBRO:` comments in `index.html`. Palette, type scale and spacing are the custom properties at the top of `styles.css`.

The layout is designed at 360 px first and widens at 760 px. There is no build step, no framework and no network request.
