# Small static site

Three linked pages (home, about, contact) with a shared header, footer and one stylesheet.

Run: open `index.html` in a browser, or serve the folder with `python3 -m http.server 8000`.

Edit the sample text and the contact address marked with `KIWIBRO:` comments. Change the palette and fonts in the custom properties at the top of `styles.css`.

Navigation marks the current page with `aria-current="page"`; copy the same header and footer into any new page you add and update the links.
